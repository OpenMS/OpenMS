### Configuration differences that matter

**Version:** official Sage release asset `v0.14.7`, source tag commit `99407db6e3754b31a9b88b7316a0aee67293c93f`. The binary reports `sage 0.14.6`, and the source tag retains that Cargo package version; the asset and hashes identify the tested build. Binary SHA256: `d3820543a31bfa2a556e04f91719204ce0ac6f34dcca6670314a13df87064625`. This uses the official precompiled Linux x86_64 binary, without source changes.

Matched search settings: full Trypsin/P (`cleave_at=KR`, `restrict=null`, `c_terminal=true`, `semi_enzymatic=false`), two missed cleavages, length 7–40, peptide mass 100–9000 Da, fixed CAM(C), at most one oxidation(M), fixed TMT6plex/TMTpro on K and peptide N-termini where appropriate. Shared external decoys: `generate_decoys=false`, `decoy_tag=DECOY_`. Precursor ±20 ppm (TMTpro ±50 ppm), known charge 2–5, `isotope_errors=[-1,2]` (subtract isotope mass, opposite sign to ProSE), no precursor calibration. Fragment ±0.5 Da for the six CID files; ±20 ppm for the other 14.

Native Sage scoring/preprocessing is retained: deisotope=true (actual code default), top 150 peaks, min 15 peaks, min 4 matched peaks, fragment charges up to precursor charge minus one, index fragment mass bounds 150–2000 Da (`fragment_min_mz`/`fragment_max_mz` are applied to neutral masses before charge expansion in this release), b/y ions and preliminary-index `min_ion_index=2`. That parameter excludes b1/b2/y1/y2 from Sage’s preliminary index, while full scoring regenerates all b/y ions; its semantics differ from ProSE’s. Top 10 PSMs, chimera=false, wide_window=false; RT/mobility prediction and quantification off. Four Rayon/OpenMP threads; telemetry disabled.

Sage’s initial-M clipping is absent in this release, as in the historical ProSE builds; pinned ANDES includes it. Sage internally drops target-identical decoy peptides and deduplicates peptide forms. These are matched benchmark settings with native engine behavior, not identical complete search spaces or an untouched Sage default search.

**Percolator input:** normalize scan IDs, peptide/modification notation, observed neutral ExpMass and theoretical CalcMass using the same frozen spectrum provenance and pinned pyOpenMS modification database. Remove raw/predicted RT and mobility columns and `posterior_error` (a same-run Sage LDA/FDR output). Keep the other native numeric features. Sort by scan/rank/peptide/label/isotope before assigning stable PSM IDs. All features are finite; both labels are present; no redundant hypotheses remain. Every Percolator run reads the full PIN and yields at most one accepted PSM per scan. Requested and resolved JSON configurations are in `reference/jobs.json` inside the supplement.

### Repeat or extend the comparison

The supplement README contains the complete bootstrap/download commands with checksums. After its setup, place `sage-benchmark` next to `prose-andes-reproduction` and run:

```bash
python3 prose-andes-reproduction/reproduce.py inputs
python3 prose-andes-reproduction/reproduce.py check-inputs
python3 sage-benchmark/run_sage.py
python3 sage-benchmark/evaluate_sage.py --require-complete --write
```

This performs 20 Sage searches and 60 Percolator runs. The evaluator checks all per-file counts/native counts and canonical PIN hashes against the archived reference. Use `--output-root` for independent repeats; report discrepancies rather than changing expectations. Raw Sage output, canonical PIN and Percolator target/decoy tables remain available in each regenerated job directory.

Validation: all 20 prepared mzML hashes and three FASTA hashes match the original benchmark, all 60 Percolator inputs are complete, and every stored canonical PIN and target/decoy output hash was verified. An initial incomplete export was rejected by these checks and regenerated; only validated final outputs are included.

Independent repeat searches of `velos_125_R1` (CID) and `eclipse_tmtpro_10855` (labelled HCD), followed by all three Percolator seeds, produced **byte-identical normalized PIN files, identical seed counts and identical common native TDC counts**. These two extra searches/six rescoring runs are recorded in `replay_checks.json` and `reference/replays` in the supplement.

The original coverage limits remain: two vendors/six models/seven acquisition groups, sampled DDA MS2 only, no SCIEX/Waters, ETD/DIA or independently validated true FDR. Do not infer a universal engine ranking from this matrix.

## 4. Exact search and evaluation protocol

| Setting | ProSE | ANDES |
| --- | --- | --- |
| Digestion | `Trypsin/P`, full specificity, 2 missed cleavages | Pinned default Trypsin, cleavage after K/R, 2 missed cleavages |
| Peptide length | 7–40 | 7–40 |
| Precursor charge | Known charges 2–5 | `--charge 2..5` |
| Precursor tolerance | ±20 ppm; ±50 ppm for TMTpro | Same |
| Isotope errors | `precursor:isotope_error_min=-2`, `max=1` | `--isotope-error=-1..2` (opposite sign convention) |
| Precursor calibration | Off | `--precursor-cal off` |
| Fragment tolerance | 0.5 Da or 20 ppm as above | Resolved by pinned auto model; timsTOF exception above |
| Scoring / fragment charges | Auto: calibrated/multiple for low resolution; HyperScore/single for high resolution | Native auto model and shipped model store |
| Fragment/index and peak settings | Deisotope auto; indexed fragment m/z 150–2000; local top 20 per 100 Da; `peaks:keep_n=0` | Native engine preprocessing |
| Candidate selection | At most 50 candidates scored, minimum 5 matched ions, minimum ion index 2, fragment charge up to 2 | Native candidate selection |
| Reported candidates | Top 10; internal PSM/protein FDR filters set to 0 for export | `--top-n 10` |
| Latest measured ProSE default | Deduplication on; window auto; query processed; extra local evidence off | Auto model |
| Initial methionine cleavage | Not yet present in these ProSE builds | Included by pinned ANDES candidate enumeration |
| Execution | 4 OpenMP threads, no database chunking | 4 threads; mmap candidate index; cache 200,000 |

The shared digestion, modification and tolerance settings do not make the engines' entire search spaces/features identical. In particular, historical ProSE lacks initial-M clipping, while ANDES includes it. Keep this distinction when interpreting cross-engine differences.

For ProSE's latest measured default, `peaks:window_type=auto` resolves to `jump_full` at ≤0.1 Da / ≤100 ppm and to legacy `jump` otherwise. The baseline auto arm predates the window fix and peptide deduplication. The exact source pin controls defaults not explicitly present in the JSON. In the saved parameters, the older `precursor:isotopes=[0,1]` field coexists with the explicit min/max range; replay the saved dictionary unchanged with its pinned source.

**PIN normalization and Percolator:** run `native_dedup/export.py` for both engines. All candidates for a scan receive the same observed neutral `ExpMass=(precursor_mz−1.007276466771)×charge`; `CalcMass` comes from `AASequence.getMonoWeight()`. ## 7. Reproduce the suite

Source downloads total approximately 13.16 GB (largest 2.73 GB). Allow at least 15 GB for a subset and more for retained results/builds/full runs. ## 8. Coverage limits and future extensions

The suite covers Thermo and Bruker measurements, low-resolution ion-trap CID, high-resolution Orbitrap/Astral/TOF fragments, unlabelled samples, TMT6plex, TMTpro, mixed-species samples and plasma. Six instrument models are not exhaustive coverage. In particular, these results do not validate SCIEX/Waters, ETD/EThcD, DIA, native raw conversion, full-run calibration, quantification or broad PTM localization.

ANDES agreement is not ground truth. Counts at nominal 1% q-value do not establish true FDR. Data series overlap known ANDES benchmarks; training-set independence has not been established. This is not a blind comparison. Astral A2 was exploratory. Regressions on individual files remain visible in the tables; do not report only a pooled gain.

Future work tracked here:

- [ ] Rerun all 20 paired measurements for the ProSE methionine-clipping change (#10358), with an explicit on/off comparison and documented target/decoy handling; do not overwrite these historical results.
- [ ] Add SCIEX TripleTOF 5600+/6600 data, e.g. PXD020785, after validating a common centroiding path (the inspected files were profile mode).
- [ ] Add Waters and ETD/EThcD DDA measurements with public converted spectra and matched sequence databases.
- [ ] Add phosphoproteomics / broader variable-modification searches as a separate matrix.
- [ ] Add an independent truth or entrapment-based assessment of actual FDR and a held-out evaluation set.
