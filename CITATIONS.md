# Citing OpenMS

If you use OpenMS in your research, please cite the following publications:

## OpenMS 3 (2024)

Pfeuffer, J., Bielow, C., Wein, S., Jeong, K., Netz, E., Walter, A., Alka, O., Nilse, L., Colaianni, P.D., McCloskey, D., Mülleder, M., Meier, F., et al. (2024). OpenMS 3 enables reproducible analysis of large-scale mass spectrometry data. *Nature Methods*, 21(3), 365-367. https://doi.org/10.1038/s41592-024-02197-7

## OpenMS (2016)

Röst, H.L., Sachsenberg, T., Aiche, S., Bielow, C., Weisser, H., Aicheler, F., Andreotti, S., Ehrlich, H.C., Gutenbrunner, P., Kenar, E., et al. (2016). OpenMS: a flexible open-source software platform for mass spectrometry data analysis. *Nature Methods*, 13(9), 741-748. https://doi.org/10.1038/nmeth.3959

## OpenMS (2008)

Sturm, M., Bertsch, A., Gröpl, C., Hildebrandt, A., Hussong, R., Lange, E., Pfeifer, N., Schulz-Trieglaff, O., Zerck, A., Reinert, K., Kohlbacher, O. (2008). OpenMS - an open-source software framework for mass spectrometry. *BMC Bioinformatics*, 9, 163. https://doi.org/10.1186/1471-2105-9-163
