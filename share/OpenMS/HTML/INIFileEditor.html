INIFileEditor — An editor for OpenMS configuration files

This is a single-file, offline HTML replacement for the Qt-based INIFileEditor. It edits TOPP tool parameter files (Param XML, usually *.ini).

Usage

Values can be edited by double-clicking a row or pressing F2 / Enter. The documentation of each value is shown in the panel below the tree. Use the arrow keys to navigate, ←/→ to collapse/expand sections.

Edited values are highlighted until the file is saved. Orange parameters are required.

Privacy

Everything runs locally in your browser; the file is never uploaded anywhere.
