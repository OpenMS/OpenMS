# ProSE issue #9197 fixes — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fix ProSE multi-file run data loss on merged-write failure (item 1a), the underlying `target+decoy` dangling-protein-reference crash (item 1b), and the silent decoy-stripping behavior caused by `FDR:PSM` running before Percolator (item 3).

**Architecture:** All changes confined to `src/topp/ProSE.cpp` (the TOPP wrapper). Per-file output writes get reordered (pin → Percolator → FDR re-apply → idXML/qpx/parquet) so pin contains raw HyperScore as intended for external rescoring. Merged-write block moves AFTER the per-file loop and is wrapped in try/catch so its failure no longer discards per-file outputs. A one-line `IDFilter::removeDanglingProteinReferences` call closes the `target+decoy` evidence-pointing-to-deleted-decoy gap. `FDR:PSM` deferral mirrors the existing `FDR:protein` deferral pattern.

**Tech Stack:** C++ (OpenMS), CMake, ctest. No header changes; no new public API.

**Source spec:** `docs/superpowers/specs/2026-04-21-prose-9197-fixes-design.md`
