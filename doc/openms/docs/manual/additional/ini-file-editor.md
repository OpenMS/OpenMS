INIFileEditor
============

Can be used to visually edit INI files of TOPP tools. INIFileEditor is one of the graphical tools of OpenMS, which are
installed with the [OpenMS-TOPP-GUI](https://github.com/OpenMS/OpenMS-TOPP-GUI) installer on top of OpenMS
(see [Installation](/about/installation.rst)).

The values can be edited by double-clicking or pressing <kbd>F2</kbd>.

The documentation of each value is shown in the text area on the bottom of the widget.
