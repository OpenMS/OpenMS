openms-thermo-bridge: third-party notices
=========================================

The managed assemblies in this folder are built by openms-thermo-bridge 0.3.0
(https://github.com/OpenMS/openms-thermo-bridge), which OpenMS uses to read Thermo Fisher .raw
files. Its native library links nethost from the .NET host pack of the .NET SDK the build
used. Each entry names the package, its license, copyright and source code.

ThermoFisher.CommonCore.*.dll are licensed by Thermo Fisher Scientific under the RawFileReader
license, which OpenMS installs as share/OpenMS/LICENSES/ThermoRawFileReader-License.doc.
